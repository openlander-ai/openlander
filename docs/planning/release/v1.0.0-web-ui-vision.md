## Direction Update (2026-03-25)

이 문서는 원래 "Button-to-Chat" 패턴을 기술했다. 실제 구현 과정에서 방향이 바뀌었다.

### 무엇이 바뀌었나

**원래 계획 (Button-to-Chat)**:

- 버튼 클릭 → 채팅창 열림 → AI가 명령어 처리
- 챗봇이 메인 AI 인터페이스
- API key 있으면 챗봇, 없으면 직접 API 호출

**실제 구현 (Smart Deploy Terminal)**:

- 버튼 클릭 → 배포 터미널 열림 → AI가 터미널 안에서 인라인으로 개입
- 챗봇 패널 없음 → **v0.9.0에서 AgentPanel 추가**. 배포 터미널과 별도로 범용 AI 어시스턴트 패널이 존재 (DEC-042 참조)
- 진단(빨강)과 처방(보라 Accent Block)이 터미널 스트림 안에서 분리 표시
- 성공 시 자동 접힘, 에러 시 펼침

### Agent Mode (v0.9.0 — 추가)

v0.9.0에서 **Agent Mode**가 추가되었다. 이는 Smart Deploy Terminal과 별도의 범용 AI 어시스턴트 인터페이스다.

- **목적**: 배포 관련 일반 질문, 플랫폼 사용법, 설정 조언 등 범용 AI 어시스턴트
- **구현**: ChatGPT 스타일 채팅 패널 (AgentPanel) — 사이드바의 Dashboard/Agent 토글로 전환
- **특징**: 멀티턴 대화, 마크다운 렌더링, 도구 호출 시각화, 세션 DB 저장
- **공존**: Smart Deploy Terminal과 다른 목적으로 공존. 배포 중 인라인 AI는 터미널, 일반 질문은 Agent Mode

### 왜 바뀌었나

챗봇 패턴을 설계하면서 Vercel을 분석했다. Vercel은 배포 플로우에 AI를 넣지 않는다. OpenLander의 차별점은 "배포 중에 AI가 함께 있다"는 것인데, 챗봇은 배포 플로우 밖에 있는 별도 인터페이스다. 터미널 안에서 AI가 직접 개입하는 방식이 더 자연스럽고 차별점이 명확하다.

또한 챗봇은 세션 관리, 대화 히스토리, 멀티턴 상태 등 복잡도가 높다. 터미널 인라인 방식은 배포 이벤트 스트림에 AI 이벤트를 추가하는 것으로 구현이 단순하다.

### 핵심 설계 원칙 (변경 없음)

1. **단일 경로** — 모든 액션은 하나의 파이프라인을 탄다
2. **옵셔널 AI** — API key 없어도 제품이 동작. AI는 "더 좋은 경험"
3. **투명성** — AI가 뭘 하는지 유저가 실시간으로 봄
4. **점진적 학습** — 버튼으로 시작 → AI 개입 과정을 봄 → 자연스럽게 이해

## 핵심 전환 (원래 계획)

> **참고**: 아래는 원래 Button-to-Chat 설계다. 실제 구현은 위 "Direction Update" 참조.

**AS-IS** (현재): 웹 = 모니터링 대시보드. 액션 버튼은 직접 API 호출.
**TO-BE (원래 계획)**: 웹 = 대시보드 + 챗봇. 액션 버튼은 챗봇 명령어 입력.
**실제 구현**: 웹 = 대시보드 + 스마트 디플로이 터미널. AI는 터미널 스트림 안에서 인라인 개입.

---

## 왜 이렇게 바꾸나

### 문제: 버튼과 AI의 동작 불일치

```
버튼: map_domain("api.myapp.com") → DNS 등록 → 끝
AI:   "api.myapp.com 연결해줘" → DNS 등록 → NEXT_PUBLIC_API_URL 업데이트
      → 프론트 재배포 → CORS 확인 → 백엔드도 필요하면 재배포
```

같은 기능인데 AI가 하면 후속 작업까지 자동으로 챙김. 두 경로가 공존하면 버튼 사용자만 손해.

### 해결: 버튼 = AI 단축키

버튼 클릭 → 채팅창에 명령어 자동 입력 → AI가 전체 플로우 처리.

## 동작 모델

### API Key 있을 때

```
[Deploy 버튼] 클릭
    ↓
채팅창 열림 + "deploy myapp" 자동 입력
    ↓
AI: 레포 분석 → 서비스 감지 → DB 필요 → 생성 → 환경변수 주입 → 배포 → 모니터링
    ↓
유저: 실시간으로 AI가 뭘 하는지 봄 (신뢰 형성)
```

```
[Map Domain 버튼] 클릭
    ↓
채팅창: "map api.example.com to myapp"
    ↓
AI: DNS 등록 → 환경변수 업데이트 → 관련 프로젝트 재배포
```

### API Key 없을 때

```
[Deploy 버튼] 클릭
    ↓
기존과 동일: pipeline.redeploy() 직접 호출
```

제품이 API key 없이도 정상 동작. 키 등록은 "더 나은 경험"으로의 자연스러운 업그레이드 경로.

## 웹 UI 구성

### 대시보드 (API key 무관 — 항상 제공)

| 영역            | 기능                                |
| --------------- | ----------------------------------- |
| 프로젝트 목록   | 상태 표시, 필터/검색                |
| 프로젝트 상세   | 빌드 로그, 환경변수, 도메인, 서비스 |
| 배포 히스토리   | 빌드 기록, 롤백 이력                |
| 서비스 관리     | DB, Redis, RabbitMQ 등 상태         |
| 시스템 모니터링 | 디스크, 메모리, 컨테이너 상태       |

### 스마트 디플로이 터미널 (실제 구현)

챗봇 패널 대신, 배포 터미널 안에서 AI가 인라인으로 개입한다.

| 요소          | 설명                                                       |
| ------------- | ---------------------------------------------------------- |
| 배포 터미널   | 빌드 로그 스트리밍 + AI 이벤트 인라인 표시                 |
| 진단 블록     | 빨강 — 에러 원인 분석                                      |
| 처방 블록     | 보라 Accent Block (좌측 보더 + 연한 보라 배경) — 복구 방향 |
| 자동 접힘     | 성공 시 접힘, 에러 시 펼침                                 |
| 복구 1회 제한 | UI 레벨에서 자동 복구 1회만 허용 (DEC-044)                 |
| AI 버튼 구분  | 스파클 아이콘으로 AI 버튼 시각적 구분 (DEC-046)            |

### 버튼 동작 분기 (실제 구현)

16개 버튼 중 4개만 AI 경유, 12개는 직접 API 호출.

```
AI 버튼 (스파클 아이콘, API key 필요):
  Deploy, Redeploy, Map Domain, Rollback

직접 버튼 (API key 무관):
  Stop, Restart, Share, Delete, 환경변수 CRUD, 도메인 CRUD 등
```

API key 없으면 AI 버튼도 직접 API 호출로 폴백.

## 구현 스코프 (원래 계획 — 참고용)

> 아래는 Button-to-Chat 기준 원래 계획이다. 실제 구현은 위 섹션 참조.

### Phase 1: 챗봇 기반 구축 (미구현)

- 채팅 패널 컴포넌트 (메시지 렌더링, 스트리밍)
- LLM API 연동 (API key 설정 UI)
- 기본 명령어 처리 (deploy, redeploy, stop, restart)

### Phase 2: 버튼-챗봇 연결 (미구현)

- 기존 액션 버튼에 분기 로직 추가
- 명령어 자동 입력 + 채팅 패널 자동 열기
- API key 미설정 시 기존 동작 유지

### Phase 3: UX 다듬기 (미구현)

- 명령어 자동 완성
- 진행 상태 시각화 (빌드 단계 표시)
- 에러 시 자동 진단 결과 인라인 표시
- 히스토리 (이전 대화 보기)

## 설계 원칙

1. **단일 경로** — 모든 액션은 궁극적으로 하나의 파이프라인(MCP 도구 체인)을 탄다
2. **옵셔널 AI** — API key 없어도 제품이 동작. AI는 "더 좋은 경험"이지 "필수"가 아님
3. **투명성** — AI가 뭘 하는지 유저가 실시간으로 봄 (블랙박스 아님)
4. **점진적 학습** — 버튼으로 시작 → AI가 뭘 하는지 봄 → 자연스럽게 직접 타이핑으로 전환
