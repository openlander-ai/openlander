# GUIDE-02: Page Skeleton

## Page Header

A page header includes:

- title or breadcrumb
- optional subtitle / description in muted text
- relevant status chips
- primary actions on the right when needed

Descriptions should be one line where possible and should explain the current
resource, not repeat the title.

## Card Grid

Project and service cards use this shape:

- icon + title
- one-line subtitle
- optional status pills
- optional tag chips
- compact metadata row
- primary action or click target

Cards should degrade gracefully when optional metadata is absent.

## Detail Tabs

Tabs split user intent, not database tables. Typical service-detail tabs include
Overview, Logs, Deployments, Monitoring, Environment, Domains, and advanced
runtime actions when applicable.
