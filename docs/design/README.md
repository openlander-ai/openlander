# OpenLander Design Notes

This directory contains public, sanitized product-design notes used by code
comments and regression tests. It intentionally excludes internal QA logs,
competitive analysis, local-machine paths, and unreleased implementation plans.

## Contents

- `v0.1/source-notes/` — locked v0.1 surface notes and decisions.
- `v1.0/` — design-system and interaction guides that still explain current UI
  structure.

When implementation comments cite these files, keep the cited section public and
stable. Internal planning belongs outside the public repository.
