# v0.1 Product Surface Spec

This is the public, sanitized v0.1 surface contract. It records the user-visible
shape of the product without private QA notes or implementation history.

## Login

- First boot shows setup mode when no admin password exists.
- Sign-in mode shows password input only.
- Setup mode requires password + confirmation and enforces the configured
  password policy.

## Sidebar And Account

- Sidebar groups primary product surfaces under Workspace and system-level setup
  under Settings.
- The footer account card opens account actions such as Change password and Sign
  out.

## Your Agent

- Your Agent is the MCP setup page.
- v0.1 presents org-level agent connection state, token setup, and copyable MCP
  configuration in one place.
- Project-scoped MCP actions may be surfaced on project pages where relevant.

## Web Server

- The Web Server page reads backend models under `/api/web-server/*`.
- v0.1 exposes proxy status, route inventory, port allocations, and external
  containers.
- Throughput is intentionally not synthesized when no trustworthy metric source
  exists.

## Git Providers

- v0.1 supports GitHub as the first git-provider integration.
- The Git Providers settings page displays connection state, identity metadata,
  and setup/disconnect actions.

## SSH Keys

- SSH key management is deferred out of v0.1.
- The settings surface may show a disabled/deferred state instead of exposing a
  partial key-management workflow.

## Settings Tabs

- Settings is system-level, not personal-account configuration.
- v0.1 keeps only tabs that have backed, tested product surfaces.
