# Code of Conduct

OpenLander is an open-source project for self-hosted deployment workflows. We want the project to
be useful, direct, and respectful for maintainers, contributors, and users.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent, but be precise when discussing technical tradeoffs.
- Keep issues and pull requests focused on the project.
- Give actionable feedback and include reproduction details when reporting bugs.
- Respect maintainer time and decisions.

## Unacceptable Behavior

- Harassment, threats, or discriminatory language.
- Personal attacks or repeated hostile comments.
- Publishing private information without permission.
- Spam, off-topic promotion, or intentionally disruptive behavior.
- Security disclosure in a public issue before maintainers have had a chance to respond.

## Enforcement

Maintainers may edit, hide, or delete comments; close issues or pull requests; block accounts; or
take other reasonable steps to keep the project safe and productive.

If you need to report conduct concerns, contact the maintainers through the repository security or
contact channels listed in `SECURITY.md`.
