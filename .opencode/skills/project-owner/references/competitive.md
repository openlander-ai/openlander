> PM이 아이데이션, 차별화 전략, 사용자 이해에 참조하는 문서.

## 시장 지형

### Agentic Coding 시대의 배포 문제

2024-2026년, AI 코딩 도구가 급격히 보급됨:

- **Cursor** — AI 코드 에디터 (가장 대중적)
- **Claude Code** — CLI 기반 AI 코딩 에이전트
- **GitHub Copilot Workspace** — PR 기반 자동 코딩
- **Devin, Windsurf, Cline** — 자율형 코딩 에이전트

**결과**: 코드를 만드는 건 쉬워졌지만, **배포는 여전히 수동**이고 전문 지식 필요.

**핵심 갭**: 코딩 에이전트는 서버 상태를 모른다. 배포를 시도해도:

- "포트 충돌" → 재시도 → 실패 → 루프
- "컨테이너 이름 중복" → 에러 → 분석 불가
- "프록시 설정 오류" → 접속 불가 → 원인 파악 불가

→ **OpenLander는 이 갭을 메운다**: MCP로 서버 상태를 코딩 에이전트에 전달.

## 경쟁 제품 상세 분석

### Coolify (⭐ 37k+)

**포지셔닝**: Self-hosted Heroku/Vercel alternative
**인터페이스**: 웹 대시보드 (GUI)
**타겟**: 인프라를 아는 개발자가 스스로 관리

| 항목               | Coolify                | OpenLander             |
| ------------------ | ---------------------- | ---------------------- |
| 설치               | docker compose (3-5분) | npm i -g (1분)         |
| 인터페이스         | 웹 대시보드 (폼/버튼)  | TUI 채팅 (자연어)      |
| AI 통합            | ✗ (없음)               | ✓ (LLM 에이전트 + MCP) |
| 코딩 에이전트 연동 | ✗ (불가)               | ✓ (MCP 프로토콜)       |
| 멀티 서버          | ✓ (SSH 기반)           | ✗ (단일 서버)          |
| DB 관리            | ✓ (풍부)               | △ (기본 프로비저닝만)  |
| 커뮤니티           | 대형 (37k stars)       | 초기 단계              |

**Coolify의 약점 (OpenLander 기회)**:

- AI가 전혀 없음 → 모든 설정을 사용자가 수동으로
- MCP 통합 불가 → 코딩 에이전트에서 배포 불가
- 러닝커브 높음 → 대시보드가 복잡함

**Coolify의 강점 (OpenLander이 따라가기 어려운 것)**:

- 멀티 서버 관리
- 성숙한 DB 관리 (백업, 복원, 마이그레이션)
- 대형 커뮤니티 + 문서

### Dokploy (⭐ 13k+)

Coolify와 유사하지만 더 단순. Docker Compose 중심.

| 항목         | Dokploy  | OpenLander        |
| ------------ | -------- | ----------------- |
| 복잡도       | 중간     | 낮음              |
| AI           | ✗        | ✓                 |
| Compose 지원 | ✓ (핵심) | ✓ (있지만 부차적) |
| 멀티 서버    | ✓        | ✗                 |

### Kamal (Rails/DHH)

Ruby on Rails 생태계. Docker + SSH 기반 배포.
OpenLander와 타겟이 다름 (Rails 전용 vs 범용).

### Vercel / Railway / Render (클라우드)

| 항목    | 클라우드 PaaS      | OpenLander      |
| ------- | ------------------ | --------------- |
| 비용    | $10-50+/서비스/월  | $0 (셀프호스트) |
| 제어    | 제한적             | 완전            |
| 락인    | 높음               | 없음            |
| AI 통합 | 부분적 (Vercel v0) | 네이티브        |

**클라우드의 약점**: 비용 누적, 벤더 락인, 커스터마이징 제한.
**클라우드의 강점**: 제로 인프라 관리, 글로벌 CDN, 자동 스케일링.

## OpenLander의 유니크 포지션

```
            AI 통합
              ↑
              │     ★ OpenLander
              │     (AI + 셀프호스트 + MCP)
              │
              │
   ←──────────┼──────────→
  셀프호스트   │       클라우드
              │
  Coolify ●   │     ● Vercel
  Dokploy ●   │     ● Railway
  Kamal ●     │     ● Render
              │
              ↓
           전통적 (비 AI)
```

**아무도 차지하지 않은 포지션**: AI 네이티브 + 셀프호스트 + 코딩 에이전트 통합.

## 사용자 페르소나

### Persona 1: DevOps 엔지니어 "민수" (1차 타겟)

**프로필**: 백엔드/DevOps, 경력 5년+, 팀의 서버 관리 담당
**현재 상황**:

- Mac Mini/Linux 서버에 Docker 컨테이너 10-30개 운영
- 팀원들이 Cursor/Claude Code로 앱을 쏟아냄 → 배포 요청 폭증
- 하루에 배포 5-10회. 수동으로 docker build/run/traefik 설정
- Coolify 사용 중이지만, 팀원들이 대시보드 사용법을 배우려 하지 않음

**페인포인트**:

- "배포해주세요" 슬랙 메시지가 하루 종일 옴
- 코딩 에이전트가 서버에서 멋대로 배포 시도 → 충돌 → 수습
- 환경변수 관리가 엉망 (팀원마다 다른 .env)
- 새 서비스 추가할 때 포트/도메인 설정이 번거로움

**OpenLander 가치**:

- 팀원들이 직접 채팅으로 배포 → 민수에게 요청 안 와도 됨
- MCP로 Cursor/Claude Code가 직접 배포 → 수동 개입 제거
- **서버 상태 인식으로 충돌 원천 방지** ← v0.0.9 핵심

### Persona 2: AI 코딩 사용자 "지연" (2차 타겟)

**프로필**: 비전공자/주니어, Cursor로 앱을 만들 수 있음, 인프라 지식 없음
**현재 상황**:

- Cursor로 Next.js 앱 만듦 → "이걸 어떻게 인터넷에 올리지?"
- Vercel은 무료 티어 한계 → 유료 전환 부담
- Docker? 들어본 적은 있지만 써본 적 없음
- 집에 Mac Mini가 있거나, 월 $5 VPS를 생각 중

**페인포인트**:

- 배포 방법을 모름 (Docker, 프록시, SSL 전부 생소)
- Vercel 비용이 프로젝트마다 쌓임
- 로컬에서 돌리면 외부 접근 불가

**OpenLander 가치**:

- "이 레포 배포해줘" 한 마디로 끝
- Docker 몰라도 됨 (자동 Dockerfile 생성)
- 월 $0 (셀프호스트)

### Persona 3: 코딩 에이전트 자체 (MCP 클라이언트)

**프로필**: Cursor, Claude Code 등 IDE에 내장된 AI 에이전트
**현재 상황**:

- 코드는 잘 짬, 배포는 못함
- 서버 상태를 모르니까 배포 시도 → 실패 → 루프

**OpenLander 가치**:

- MCP로 `deploy_project`, `list_projects`, `get_logs` 등 호출
- `get_server_context` (v0.0.9 계획)로 서버 전체 상태 파악 → 정확한 배포

## 시장 트렌드 (기획 배경)

1. **MCP 프로토콜 급확산** — Anthropic이 표준화. 모든 IDE가 채택 중. → OpenLander의 MCP 도구가 자연스럽게 노출.
2. **셀프호스트 회귀** — 클라우드 비용 피로감. Hetzner/Fly.io 성장. → 셀프호스트 배포 도구 수요 증가.
3. **AI 코딩 도구 폭발** — Cursor 100M+ ARR. Claude Code 급성장. → 코딩은 쉬워졌지만 배포 갭 확대.
4. **1인 개발자 증가** — AI 덕분에 혼자서 제품 만드는 사람 급증. → 인프라 관리 부담 = 병목.
